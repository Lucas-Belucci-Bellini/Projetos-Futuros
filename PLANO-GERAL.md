# Plano Geral de Estudos

## Objetivo

Construir uma base sólida para faculdade, web, jogos, sistemas, automação, dados e projetos pessoais.

## Sessão padrão

- 10–15 min: recuperação ativa sem consultar.
- 30–45 min: teoria.
- 30–60 min: exercícios.
- 15–30 min: aplicar em projeto.
- 5–10 min: registrar erros e dúvidas.

## Revisão

Voltar ao assunto no mesmo dia, depois de alguns dias, uma semana depois e novamente após um mês, ajustando o intervalo conforme a dificuldade.

## Perguntas de memória

Para qualquer conceito, responder:

- O que é?
- Para que serve?
- Como escrevo?
- Quando uso?
- Qual erro comum?
- Onde já usei no meu GitHub?

## Progressão

### Fundamentos

Lógica, algoritmos, tipos, variáveis, decisões, laços, funções, estruturas de dados simples e depuração.

### Programação estruturada

Modularização, tratamento de erros, arquivos, testes e organização.

### Orientação a objetos

Classes, objetos, encapsulamento, herança, interfaces, polimorfismo e composição.

### Sistemas e engenharia

Git, testes, debugging, banco de dados, redes, concorrência, memória, performance e arquitetura.

## Projeto após cada bloco

- variáveis → calculadora;
- condições → classificador;
- laços → gerador de dados;
- funções → biblioteca pequena;
- POO → sistema de personagens/cadastro;
- arquivos → agenda;
- SQL → banco de laboratório;
- HTTP → cliente de API;
- concorrência → processamento de tarefas.

## Regra

Não estudar uma linguagem só para aumentar o número de linguagens conhecidas. O objetivo é conseguir resolver problemas reais e explicar o que foi feito.
