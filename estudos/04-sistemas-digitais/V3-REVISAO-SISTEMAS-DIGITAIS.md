# Sistemas Digitais — V3 de Revisão para Exame

> Versão de recuperação rápida baseada nos tópicos da revisão existente.

## Mapa mental

**PORTA → EXPRESSÃO → TABELA → K-MAP → SIMPLIFICAÇÃO.**

## Regras

AND = todas as entradas em 1. OR = pelo menos uma em 1. XOR = diferentes. XNOR = iguais.

DeMorgan: negue os termos e troque + por · ou · por +.

K-map: use Gray 00,01,11,10; agrupe 1,2,4,8,...; procure o maior grupo; bordas são adjacentes; sobreposição é permitida.

SOP usa F=1; POS usa F=0.

## Pegadinhas

**Erro:** usar ordem binária normal no K-map. **Regra:** Gray.

**Erro:** confundir XOR com XNOR. **Regra:** diferentes/iguais.

**Erro:** agrupar 3 células. **Regra:** potências de 2.

**Erro:** aplicar DeMorgan sem trocar o operador. **Regra:** troca +↔· e nega cada variável.

## Método de memória

**PEGADINHA → CONSEQUÊNCIA → REGRA → EXEMPLO → RESULTADO.**
