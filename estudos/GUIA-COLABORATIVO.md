# Guia para estudar e compartilhar

## Como usar uma trilha

1. Leia o README da tecnologia.
2. Faça o módulo de fundamentos.
3. Resolva os exercícios sem abrir as soluções.
4. Use o laboratório para produzir uma variação própria.
5. Faça o simulado e crie flashcards a partir dos erros.
6. Desenvolva o projeto guiado.
7. Registre a nota de domínio e a próxima revisão.

## Como estudar em grupo

- Uma pessoa apresenta o conceito em até cinco minutos.
- Outra pessoa propõe um caso limite.
- Todos implementam uma versão mínima.
- O grupo compara clareza, testes e decisões.
- A solução só é aberta depois que todos registrarem uma tentativa.

## Como contribuir

Uma contribuição deve explicar o objetivo, incluir exemplo executável, registrar pré-requisitos e evitar depender de conteúdo externo sem indicar a fonte. Correções devem preservar o nível progressivo e apontar a data da revisão.

## Convenção de arquivo

- README: porta de entrada da trilha.
- INDEX: mapa dos módulos.
- aulas: encontros guiados.
- exercicios: problemas para resolver.
- solucoes: pistas e critérios.
- projetos: entregas maiores.
- simulados: avaliação.
- flashcards: recuperação ativa.
- referencias: fontes e versões consultadas.
