# Projetos de CSS

## Projeto guiado — dashboard responsivo

Construa uma versão mínima, uma versão resistente e uma versão apresentável para outra pessoa.

### Requisitos

- [ ] Objetivo escrito em uma frase.
- [ ] Estrutura explicada.
- [ ] Exemplo reproduzível.
- [ ] Tratamento de pelo menos uma falha.
- [ ] Testes ou roteiro de teste.
- [ ] Registro de limitações.

## Projeto em dupla

Uma pessoa implementa e outra escreve testes, documentação e revisão. Troquem os papéis no segundo incremento. A revisão deve apontar uma melhoria concreta e uma decisão correta.

## Projeto livre

Escolha um problema real da faculdade ou de casa que use **cascade, flexbox, grid, responsividade**. Não aumente o escopo antes de concluir a versão mínima.

## Avaliação

Clareza __/2 · funcionamento __/2 · testes __/2 · organização __/2 · explicação __/2.
