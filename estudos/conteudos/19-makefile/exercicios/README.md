# Exercícios de Makefile

Resolva primeiro sem consultar as soluções. Registre entradas, saídas esperadas e o que aprendeu.

## Progressão

1. Reproduza o exemplo build: echo compilando com valores diferentes.
2. Faça uma variação usando **targets, dependências, phony, flags**.
3. Processe uma entrada vazia, uma entrada limite e uma inválida.
4. Separe a solução em duas responsabilidades.
5. Adicione uma saída legível para uma pessoa.
6. Adicione uma saída estruturada para uma máquina.
7. Escreva três testes e faça um teste manual.
8. Encontre e corrija um erro introduzido de propósito.
9. Faça revisão de clareza, segurança e portabilidade.
10. Aplique tudo no projeto **pipeline de build**.

## Entrega

- Código ou marcação executável.
- Como executar.
- Exemplo de entrada e saída.
- Dificuldade encontrada.
- Dúvida que ainda permanece.
