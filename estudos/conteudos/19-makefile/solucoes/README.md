# Soluções comentadas de Makefile

As soluções devem ensinar o raciocínio, não apenas entregar código pronto. Antes de ler, tente resolver os exercícios.

## Método de correção

1. Compare a saída obtida com a saída esperada.
2. Localize o primeiro ponto em que os estados divergem.
3. Formule uma hipótese sobre a causa.
4. Faça a menor alteração possível.
5. Execute novamente e registre a evidência.

## Critérios

- **Correto:** produz o resultado esperado nos casos normais.
- **Resistente:** trata entradas inválidas e falhas previsíveis.
- **Legível:** nomes e organização explicam a intenção.
- **Testável:** outra pessoa consegue reproduzir o resultado.
- **Responsável:** considera segurança, custo e portabilidade.

## Pistas por exercício

- Exercícios 1–2: reduza o problema a entrada, transformação e saída.
- Exercícios 3–4: escreva os casos de borda antes do código.
- Exercícios 5–7: extraia uma responsabilidade por vez.
- Exercícios 8–9: use uma ferramenta de diagnóstico, não apenas tentativa e erro.
- Exercício 10: comece pelo menor incremento do projeto **pipeline de build**.
