# Trilha de Java

Prioridade: **Alta**. Caderno prático com código próprio, exercícios e revisão.

## Exemplo

~~~~java
static int dobro(int n) {
    return n * 2;
}
~~~~

O método recebe um inteiro chamado n e devolve o dobro desse valor. Por exemplo, dobro(4) retorna 8.
