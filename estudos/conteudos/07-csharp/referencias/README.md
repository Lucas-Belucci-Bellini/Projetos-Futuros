# Referências de C#

Use as fontes nesta ordem:

1. Documentação oficial e especificação da tecnologia.
2. Livro ou curso estruturado que explique fundamentos.
3. Exercícios que permitam feedback.
4. Código de projetos reais e revisões de colegas.
5. Artigos e vídeos para comparar abordagens.
