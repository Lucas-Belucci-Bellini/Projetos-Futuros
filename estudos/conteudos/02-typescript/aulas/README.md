# Aulas de TypeScript

Esta pasta pode ser usada em grupo. Cada encontro deve terminar com código executável e uma dúvida registrada.

## Roteiro de 8 encontros

1. **Contexto e ambiente:** instale ou abra a ferramenta, execute type User = { name: string }; e descreva entrada e saída.
2. **Fundamentos:** estude tipos, interfaces, generics, narrowing. Reescreva três exemplos sem copiar.
3. **Dados e controle:** resolva um problema com condição, repetição ou transformação de dados.
4. **Organização:** divida a solução em funções, módulos, arquivos ou componentes adequados.
5. **Falhas:** crie casos inválidos e documente mensagens e correções.
6. **Teste:** escreva casos normal, limite e inválido.
7. **Aplicação:** avance no projeto **API de usuários**.
8. **Apresentação:** explique decisões, limitações e próximos passos para os colegas.
