# Rede

## Núcleo
- Firewall/router dedicado
- Switch principal 10/25 GbE
- VLAN separando Gaming, IA, Minecraft, Storage, gerenciamento e área pessoal
- Wi-Fi interno
- VPN para acesso remoto
- Internet satelital como link principal em áreas sem fibra
- 4G/5G como fallback

## Objetivo
Permitir que os quatro servidores e o storage funcionem como uma pequena infraestrutura de data center móvel, mantendo os serviços isolados logicamente.
