# Second Pass Gaps — Levels 0–99

Data-base: 2026-10-01.

Gap significa que nosso arquivo precisa de confirmação, expansão ou separação de versões.

## Categorias
- P0: estrutura.
- P1: conectividade.
- P1: canon.
- P1: entidades.
- P1: bases.
- P2: aparência.
- P2: mídia.
- P3: histórico editorial.

## 91–99 — concluído nesta rodada
- [x] Estrutura padronizada.
- [x] Aparência registrada.
- [x] Entidades separadas de personagens quando necessário.
- [x] Bases/comunidades separadas de pontos de interesse.
- [x] Entradas e saídas separadas.
- [x] Subníveis explicitados quando encontrados.
- [x] Estado editorial registrado.
- [x] Mídia/licença tratada separadamente.
- [x] Conteúdo sensível mantido em nível enciclopédico.

## Continuação
### 0–50
Revisar o mesmo padrão, especialmente conexões, subníveis, bases e mídia.

### 51–70
Revalidar trimmed/open for rewrite e under rewrite sem substituir histórico por inferência.

### 71–90
Revisar status, rotas fora de 0–99, entidades, instalações, imagens e subníveis.

## Critério de conclusão
Cada nível precisa ter schema completo, desconhecidos explicitados, conexões com origem/status, entidades não gráficas, bases quando publicadas, mídia com crédito/licença ou pendência e validação Rust.
