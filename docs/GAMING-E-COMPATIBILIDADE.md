# Gaming e Compatibilidade

## Objetivo
Oferecer uma experiência de jogos Linux simples, previsível e com o mínimo de configuração manual.

## Steam
- Steam como aplicativo de primeira classe.
- Proton como camada principal de compatibilidade para jogos Windows.
- Detecção automática de GPU e drivers.
- Perfis de desempenho por jogo.
- Controle simples de shader cache e espaço em disco.

## Anti-cheat
- Catalogar compatibilidade por jogo.
- Informar claramente quando um título depende de anti-cheat incompatível.
- Nunca recomendar bypass de anti-cheat.
- Trabalhar com soluções oficialmente suportadas pelos desenvolvedores.

## Gráficos
- Mesa para AMD/Intel.
- NVIDIA proprietário quando necessário para desempenho/recursos.
- Vulkan como prioridade.
- Wayland como sessão principal, com XWayland para compatibilidade.

## Ferramentas
- GameMode ou equivalente.
- MangoHud para métricas opcionais.
- Integração com controle de energia.
- Gravação de tela opcional.

## Modding
- Suporte documentado para launchers, Wine/Proton e ferramentas compatíveis.
- Diretórios de jogos facilmente acessíveis.
- Backup de saves antes de alterações arriscadas.

## Metas
- Instalação de um jogo em poucos passos.
- Detecção automática de dependências comuns.
- Diagnóstico de falha de inicialização com linguagem simples.
