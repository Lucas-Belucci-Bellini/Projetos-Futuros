# PC-04 — Compatibilidade e montagem

## Checklist
- Confirmar CPU/APU e placa-mãe AM5.
- Confirmar 16 GB ou 32 GB de RAM conforme crescimento.
- Preferir NVMe para sistema.
- Usar armazenamento separado quando o serviço crescer.
- Confirmar 2.5/10 GbE.
- Reservar espaço para expansão de RAM e SSD.

## Montagem
1. Instalar CPU, RAM e NVMe.
2. Montar cooler e placa-mãe.
3. Conectar armazenamento adicional.
4. Configurar rede de administração.
5. Instalar Debian 13.
6. Instalar Docker e monitoramento.
7. Criar backups no STORAGE-01.

## Teste de aceitação
- Boot e POST estáveis.
- RAM reconhecida.
- SSD íntegro.
- Rede funcionando.
- Containers iniciam após reboot.
- Monitoramento detecta falhas.
- Backup e restauração validados.
