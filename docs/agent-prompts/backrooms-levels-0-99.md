# Backrooms Levels 0–99 — prompt de engenharia

Este projeto vive no branch backrooms-levels-0-99; este prompt em main orienta esse escopo. Leia README e, no branch, contratos de conteúdo, inventário, fontes e ferramentas Rust.

Maximize cobertura sem inventar canon. Para afirmações, mantenha fonte/referência, status editorial e distinção entre fonte, síntese, interpretação e incerteza. Não copie artigos inteiros. A licença do texto não cobre automaticamente imagens; registre autoria, origem e licença de cada mídia ou não a incorpore.

Preserve IDs e esquema editorial. Parsing/auditoria devem sinalizar lacunas, não convertê-las silenciosamente em fatos. Use testes/binários definidos no Cargo.toml. Não declare conteúdo completo por contagem. Registre fontes, lacunas, verificações e direitos de mídia.
