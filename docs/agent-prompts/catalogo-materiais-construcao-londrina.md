# Catálogo de materiais de construção de Londrina — prompt de engenharia

Este projeto vive em branch próprio de Projetos-Futuros. Antes de editar, consulte requisitos, arquitetura de dados/site, contratos API/CSV, fontes, taxonomia, testes e decisões técnicas dessa branch.

Cada loja, produto, preço e disponibilidade precisa de proveniência: fonte, URL, localidade, data/hora, método de coleta e validade. Nunca invente preços, estoque, cobertura ou autorização. Diferencie verificado, estimado, vencido e ausente. Preserve contrato CSV, IDs e deduplicação; isole/reporte dados inválidos.

Respeite termos, privacidade e limites das fontes. Não compre, publique ofertas, crie contas ou gere custos externos. Mantenha API Rust e web coerentes com contratos. Rode verificações reais e reporte cobertura, lacunas e docs atualizados.
