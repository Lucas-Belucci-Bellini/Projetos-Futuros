## Critérios de entrada na primeira versão

Uma empresa só deve passar de candidata a listada publicamente depois de:
1. confirmar identidade, endereço/unidade e canal oficial;
2. verificar quais categorias realmente vende e atende em Londrina;
3. definir uma fonte de dados e a frequência possível de atualização;
4. confirmar se preços são públicos, sob consulta, promocionais ou condicionais;
5. registrar apenas campos com base de uso adequada;
6. manter status comercial distinto de status de fonte de dados — cadastrar uma empresa não significa que ela seja parceira.
