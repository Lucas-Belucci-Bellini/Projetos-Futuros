# Energia — arquitetura e checklist

## Objetivo

Projetar alimentação segura e redundante para servidores, storage, rede, climatização e área habitacional.

## Blocos

- entrada externa quando disponível
- UPS/nobreaks
- baterias
- inversor
- gerador de backup
- distribuição e proteção
- medição/telemetria

## Dimensionamento

Separar cargas críticas (rede, storage, controle) das cargas de alto consumo (IA, gaming e climatização). Dimensionar UPS, cabos, proteção e autonomia com base em potência real medida e margem de segurança.

## Checklist

[ ] carga máxima de cada equipamento
[ ] consumo contínuo
[ ] autonomia desejada
[ ] proteção contra surtos
[ ] aterramento
[ ] ventilação dos equipamentos
[ ] monitoramento
[ ] desligamento ordenado
[ ] integração com gerador
[ ] projeto executado por profissional habilitado
