# Documentação — padrão do projeto

Esta branch é a referência documental transversal.

## Cada subsistema deve documentar

- objetivo e escopo
- requisitos funcionais e técnicos
- peças/componentes
- compatibilidade
- orçamento e histórico de preço
- alternativas
- montagem/implantação
- testes de aceitação
- manutenção
- upgrades
- riscos e dependências
- integração com outras branches

## Regra de atualização

Toda mudança importante deve registrar data, motivo, impacto e referência. Informações que mudam com o mercado (preço, estoque e disponibilidade) devem conter data de coleta.
