# Servidores — padrão de engenharia

## Objetivo

Manter os quatro PCs independentes, com orçamento, compatibilidade e manutenção próprios.

## SERVER-01
Gaming/workstation: priorizar GPU, CPU, refrigeração, fonte e armazenamento rápido.

## SERVER-02
IA/Hermes: priorizar VRAM, PCIe, RAM ECC, plataforma workstation, fonte e refrigeração.

## SERVER-03
Minecraft: priorizar desempenho por núcleo, RAM, I/O e estabilidade; GPU não é prioridade.

## SERVER-04
Serviços: priorizar eficiência, baixo consumo, armazenamento confiável e facilidade de manutenção.

## Checklist comum

[ ] CPU
[ ] placa-mãe e QVL
[ ] RAM e capacidade máxima
[ ] GPU/TGP e dimensões
[ ] SSD/HDD
[ ] fonte com margem
[ ] cooler/airflow
[ ] rede
[ ] sistema operacional
[ ] backup
[ ] monitoramento
[ ] teste de carga
[ ] peça substituta

A documentação detalhada de cada PC fica nas branches `pc-01-gaming`, `pc-02-ia-hermes`, `pc-03-minecraft` e `pc-04-servicos`.
