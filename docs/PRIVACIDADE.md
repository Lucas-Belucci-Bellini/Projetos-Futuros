# Privacidade e Telemetria

## Princípios

- coleta mínima;
- processamento local por padrão;
- transparência;
- controle do usuário;
- dados sensíveis nunca coletados por padrão;
- serviços opcionais claramente identificados.

## Telemetria

O SO pode oferecer telemetria **opt-in** para melhorar estabilidade, contendo somente dados necessários para o objetivo escolhido.

Exemplos aceitáveis:

- versão do SO;
- arquitetura;
- versão do kernel;
- hardware genérico;
- código anônimo de falha;
- duração de uma operação técnica.

Não coletar por padrão:

- documentos;
- senhas;
- conteúdo de mensagens;
- chaves privadas;
- histórico completo de navegação;
- áudio/câmera.

## Diagnóstico local

Antes de enviar qualquer relatório, mostrar ao usuário o conteúdo que será enviado.

## Contas

A conta online nunca deve ser requisito para usar o desktop básico.

Serviços online podem oferecer:

- sincronização;
- recuperação de configurações;
- backup;
- loja de aplicativos;
- recursos opcionais de IA.

## IA local

Priorizar processamento local quando o hardware suportar. Quando uma função usar serviço remoto, informar claramente antes do envio dos dados.

## Logs

Logs podem conter caminhos de arquivos, nomes de dispositivos e outros metadados técnicos. Ferramentas de exportação devem filtrar segredos conhecidos e permitir revisão antes do compartilhamento.
