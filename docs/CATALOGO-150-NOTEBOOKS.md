## Regra final

O catálogo serve para montar o orçamento. A compra final deve comparar o **modelo exato**, não somente CPU/GPU nominal. Para notebook, TGP, refrigeração, RAM soldada, número de M.2, bateria e assistência podem mudar completamente o custo-benefício.
