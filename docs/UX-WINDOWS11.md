# UX inspirada no Windows 11

## Regra

Usar ideias de UX observadas em desktops modernos, especialmente as que tornam o sistema rápido de aprender. Não copiar identidade visual, assets, código ou marcas da Microsoft.

## Recursos desejados

### Barra de tarefas

- centralizada ou alinhamento configurável;
- aplicativos fixados;
- indicadores claros;
- agrupamento de janelas;
- áreas de sistema acessíveis sem excesso visual.

### Menu principal

- busca imediata;
- aplicativos recentes/favoritos;
- documentos recentes opcionalmente locais;
- categorias simples;
- desligar/reiniciar/bloquear em local previsível.

### Snapping

- encaixe em metade, terços e quadrantes;
- layouts para ultrawide;
- restauração do layout após reconectar monitores;
- atalhos de teclado.

### Desktops virtuais

- nomeação;
- papel de parede por desktop;
- aplicativos fixados ao desktop ou globais;
- troca rápida.

### Explorador de arquivos

- abas;
- árvore lateral opcional;
- favoritos;
- busca rápida;
- preview;
- operações em lote;
- histórico/undo quando seguro;
- indicadores de sincronização/backup.

### Configurações

Uma aplicação de configurações única com:

- rede;
- Bluetooth;
- tela;
- som;
- energia;
- armazenamento;
- usuários;
- segurança;
- atualizações;
- aplicativos;
- privacidade;
- acessibilidade;
- desenvolvedor.

### Área rápida

Painel curto para:

- Wi-Fi;
- Bluetooth;
- VPN;
- volume;
- brilho;
- modo de energia;
- modo jogo;
- captura de tela.

## Diferencial do projeto

A UX deve ter um **Centro de Controle** que mostre estado do sistema sem exigir terminal:

```text
SYSTEM STATUS
CPU       █████░  52%
GPU       ████░░  41%
RAM       ██████  68%
DISK      ███░░░  32%
NETWORK   ONLINE
SECURITY  OK
UPDATES   READY
```

O usuário pode abrir detalhes técnicos quando quiser, mantendo o primeiro nível simples.

## Modo Técnico

Usuários avançados podem ativar um painel adicional com:

- processos;
- serviços;
- logs;
- temperatura;
- drivers;
- armazenamento;
- dispositivos;
- integridade do boot;
- atualizações;
- conectividade.

## Acessibilidade

- escala de interface;
- contraste;
- teclado;
- leitor de tela;
- navegação sem mouse;
- redução de animações;
- modo daltônico quando aplicável.
