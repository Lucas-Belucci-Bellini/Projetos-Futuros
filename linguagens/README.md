## Como usar

Acesse uma linguagem somente quando ela for necessária para a aula, projeto ou revisão.

A prioridade não significa "estude agora". Ela indica o quanto vale a pena dominar aquela tecnologia para construir uma base geral.

## Dependências de aprendizado

- Portugol → lógica.
- Java/Python/JavaScript/C# → fundamentos gerais e comparação entre paradigmas.
- TypeScript → JavaScript.
- PL/pgSQL → SQL + PostgreSQL.
- ShaderLab → fundamentos de shaders + HLSL.
- Makefile → shell + conceitos de build.
- Dockerfile → shell + conceitos de build/containers.
- GDScript → fundamentos de programação + Godot.
- SQF → fundamentos de programação + contexto do Arma 3.
