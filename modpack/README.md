## Regras para versionamento

1. Não subir `.minecraft`, saves pessoais, logs, tokens, senhas ou dados de conta.
2. Preferir o manifesto/exportação oficial do launcher em vez de republicar centenas de arquivos `.jar`.
3. Antes de publicar arquivos de mods, verificar a licença e as regras de redistribuição de cada projeto.
4. Para arquivos binários grandes, avaliar armazenamento privado ou Git LFS; não transformar o Git normal em depósito de instaladores.
5. Registrar versões exatas do Minecraft, Java e loader para tornar a instalação reproduzível.
